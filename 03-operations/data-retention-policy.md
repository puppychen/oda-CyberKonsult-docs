# 資料保留政策

> **ODA Cyber Konsult - 資料保留政策**
>
> 建立日期：2026-03-16
> 狀態：📋 Phase 2 規劃中

## 1. 目的

定義系統中各類資料的保留期限、清除策略與合規要求，確保符合台灣個資法與企業資料治理需求。

## 2. 資料分類與保留期限

| 資料類別 | 保留期限 | 清除方式 | 法規依據 |
|----------|---------|---------|---------|
| **使用者帳號** | 帳號停用後 90 天 | 軟刪除 → 硬刪除 | 個資法 §11 |
| **對話記錄** | 365 天（1 年） | 自動清除（排程） | 業務需求 |
| **稽核日誌** | 730 天（2 年） | 不可刪除，歸檔至冷儲存 | 資通安全管理法 |
| **原始上傳檔案** | 清洗完成後 30 天 | 自動清除 | 個資法 §11（最小必要） |
| **去識別化後檔案** | 送入 RAG 後 90 天 | 自動清除 | 業務需求 |
| **清洗任務記錄** | 365 天 | 自動清除 | 業務需求 |
| **知識庫向量** | 無限期（手動管理） | 管理員手動刪除 | — |
| **密碼歷史** | 最近 2 代 | 超過 2 代自動清除 | 資通安全「普」級 |
| **JWT Refresh Token** | 7 天 | 過期自動失效 | 安全最佳實務 |

## 3. 清除排程（Phase 2 實作）

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  每日 02:00   │     │  每週日 03:00 │     │  每月 1 日    │
│              │     │              │     │              │
│ • 過期 Token │     │ • 過期對話   │     │ • 過期檔案   │
│ • Dead WS    │     │ • 過期任務   │     │ • 稽核歸檔   │
└──────────────┘     └──────────────┘     └──────────────┘
```

## 4. 合規要求

| 法規 | 相關條文 | 系統對應 |
|------|---------|---------|
| 個資法 §11 | 個資蒐集特定目的消失或期限屆滿時應刪除 | 上傳檔案保留期限 |
| 資通安全管理法 §18 | 資通安全事件通報與應變 | 稽核日誌 2 年保留 |
| 資通安全管理法施行細則 | 日誌保存與稽核 | 稽核日誌不可刪除 |
